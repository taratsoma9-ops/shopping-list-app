# Shopping List Application

CMPS 510 – Final Individual Project

## Project Description

The Shopping List application is a simple web application that helps users organize and manage their shopping items.

## Main Features

- Add shopping items with quantities.
- Mark items as purchased.
- Delete items from the shopping list.
- Display total, purchased, and remaining items.
- Save shopping data using localStorage.
- Validate item names and quantities.

## Technologies Used

- HTML
- CSS
- JavaScript
- Browser localStorage
- GitHub
- GitHub Pages
